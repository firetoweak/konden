# 模型配置

konden 直接连接内置供应商。`openai` 使用 API Key，`openai-chatgpt` 使用 ChatGPT 订阅授权，两者都调用 Responses API。其他供应商使用 Chat Completions。模型标识为 `provider/model`，按第一个斜杠拆分，后面的模型 ID 原样发给服务。Web 从供应商目录勾选模型；一个供应商可以选用多个模型。终端向导仍可填写服务实际支持的模型 ID。

## 终端配置向导

首次运行源码准备命令时，未填写默认模型或连接设置且终端可交互，会自动进入向导。已有完整默认设置时保留配置。之后可使用项目 Python 单独运行向导：

```powershell
# Windows，在仓库根目录执行
.\konden-env\Scripts\python.exe -m konden.initialize --configure
```

```sh
# Linux，在仓库根目录执行
./konden-env/bin/python -m konden.initialize --configure
```

向导收集供应商、隐藏输入的 API Key、本地服务地址（按需）、模型 ID 与 compact 阈值；支持的模型还可以设置推理程度。新模型必须显式填写大于 0 的 compact 阈值，按模型上下文容量留出余量。修改已有模型时回车保留当前值，密钥不会显示。

保存会保留其他供应商和候选模型，将选定模型设为新会话默认值。之后可选择发送一条短请求测试连接；测试失败保留已保存配置并显示原因。


## 个人连接文件

安装或首次启动会在 `~/.konden` 创建 `connections.json` 和 `config.json`。设置 `KONDEN_HOME` 可更换整个个人数据目录；`KONDEN_CONFIG` 只指定候选模型配置文件的位置。普通供应商的密钥保存在 `connections.json`；ChatGPT 订阅连接保存凭据文件的引用。

`connections.json` 包含全部内置供应商。下面是创建时的结构：

```json
{
  "deepseek": { "api_key": "" },
  "openai": { "api_key": "" },
  "openai-chatgpt": { "auth_file": "" },
  "qwen": { "api_key": "" },
  "stepfun": { "api_key": "" },
  "bigmodel": { "api_key": "" },
  "vllm": { "api_key": "", "base_url": "http://127.0.0.1:8000/v1" },
  "ollama": { "api_key": "", "base_url": "http://127.0.0.1:11434/v1" }
}
```

远程供应商填写自己的密钥。Qwen 使用阿里云百炼国内地址，StepFun 为阶跃星辰，BigModel 为智谱通用 API；这些远程接口地址由内置 Provider 表确定。vLLM 与 Ollama 使用本地服务地址，地址包含 `/v1`；未启用认证时密钥留空。Ollama 的模型名保留本地名称中的标签，例如 `qwen3:8b`。vLLM 模型名可以带斜杠。

所选型号需要支持工具调用，`openai` 还需要支持 Responses API。本地服务能连通不代表所选模型支持工具；vLLM 需要启用自动工具选择并配置匹配的工具解析器，见[官方工具调用说明](https://docs.vllm.ai/en/stable/features/tool_calling/)。页面的「测试」只验证一条简短请求，实际工具能力需通过工具回合核验。

### 使用 ChatGPT 订阅额度

从旧版升级时，准备命令会移除已停用的 `openai-codex` 候选和连接项，保留其他配置。旧通道是默认模型且仍有其他候选时，请先把 `config.json` 的 `model.default` 改为其中一个受支持的模型，再运行准备命令。使用旧通道的会话需要重新选择模型。

`openai-chatgpt` 通过 [Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source) 使用当前账号的订阅额度。打开运行 konden 的电脑上的 Web，在「模型配置 → 供应商与模型」展开供应商下拉列表，点击 ChatGPT 订阅右侧的「Continue with ChatGPT」。在新标签页完成授权后，返回 konden，右侧显示「已连接」勾。选中 ChatGPT 订阅即可查看模型目录。

终端用户也可在本机仓库根目录运行项目 Python 发起授权。

```powershell
# Windows
.\konden-env\Scripts\python.exe -m thinllm auth chatgpt
```

```sh
# macOS / Linux
./konden-env/bin/python -m thinllm auth chatgpt
```

授权成功后，命令输出 `openai-chatgpt` 连接的 JSON。`connections.json` 中的 `auth_file` 留空即使用默认位置 `~/.thinllm/chatgpt.json`。使用 `--auth-file` 指定独立凭据文件时，将输出的连接项填入该实例的 `connections.json`。凭据文件包含敏感信息，请保存在自己的本机目录中。

在 Web「供应商与模型」选择「ChatGPT 订阅」并勾选账号目录中的模型，再到「已选模型」保存并测试。目录和推理共用授权，临近到期时按需续期。收到授权失效提示时，重新运行同一条命令。订阅用量可在 [ChatGPT 设置](https://chatgpt.com/settings/usage) 查看。

授权失效时可从供应商下拉列表重新授权。需要隔离实例时，设置独立的 `KONDEN_HOME`，并在该实例的连接配置中指定独立的 `auth_file`。

保存连接文件后，**下一次模型调用使用新连接，无需重启**。正在进行的请求继续用原连接完成。Web 的「已配置」只表示填写了必要设置，不代表服务在线或密钥有效；页面不接收或回显密钥。连接未配置时仍能进入 Web 配置页。

「供应商与模型」的目录读取失败会区分网络通信、超时、代理连接、认证未通过（401）、拒绝访问（403）、请求受限（429）和服务异常，并给出对应处理建议。未取得完整响应时，无法判断密钥或登录凭据是否有效；不要仅凭网络错误更换密钥。

聊天与图片目录的连接错误会附请求地址、异常类型和系统错误原因；DNS、HTTPS 证书校验和连接被拒绝等已有依据的原因会直接说明。后台同时输出相同的脱敏诊断；访问日志里的 `502` 是 konden 返回给页面的状态，不代表供应商实际返回了 502。诊断不包含密钥、认证信息或地址中的查询参数。

## Web 配置与会话切换

在「新建 Bot」中可沿用默认模型，或为当前 Bot 选择其他可用模型。所选模型从第一次运行起生效。需要添加模型时，打开表单中的「模型配置」，勾选模型后点「保存并返回」。返回时会保留已填写的名字和代码目录。首页「认识你的第一位伙伴」卡片也可打开「模型配置」，第一位 Bot 使用保存的默认模型。

「已选模型」在模型名称下方显示上下文容量，目录未提供数值时显示「上下文容量未知」。在该行的「更多设置」中可以调整上下文整理阈值。测试使用该行当前模型与推理强度，可在保存之前验证，显示耗时与失败原因，不保存草稿、不改变默认模型或会话选择。

侧栏底部「设置 → 模型配置」包含「供应商与模型」「已选模型」「网络搜索」「图片生成」四页。聊天模型先从目录勾选，再汇总管理默认强度、上下文整理阈值与新会话默认模型，最后保存配置。关闭或切换设置会保留未保存修改。聊天偏好保存在 `config.json`，下面是配置后的示例：

```json
{
  "model": {
    "default": "deepseek/deepseek-v4-pro",
    "candidates": [
      {
        "model": "deepseek/deepseek-v4-pro",
        "compact_threshold_tokens": 200000
      }
    ]
  }
}
```

可按账号提供的模型 ID 添加同一供应商的 Pro、Flash 等模型。会话输入区的「会话模型」下拉只允许选择已配置连接的候选模型，选择独立保存为会话元数据。正在执行的 Step 完成后，下一次决策使用新选择；完整历史与工具结果保留。子会话继承创建时父会话的选择，随后各自独立。

修改默认值只影响新建会话。删除默认模型时可同时选择新默认值并保存，无需先逐个切换历史会话。删除模型保留会话历史和原选择；原模型已移除时，在需要继续的会话输入区选择可用模型即可，不会自动改用其他模型。在途回复保留启动时的设置。手工编辑配置遵循相同规则，损坏或非法持久配置会直接报错，不回退到旧配置。

`compact_threshold_tokens` 属于各候选模型，是触发上下文整理的输入 token 数，包含缓存命中，不是模型总容量。Web 新加入候选列表的模型默认使用 500,000 token。请按模型容量留出新消息和工具结果的余量。切换模型不会自动丢弃或裁剪历史；上下文超限等上游错误走现有失败展示。

推理档位按供应商与具体模型提供。DeepSeek、StepFun 和 ChatGPT 订阅使用目录返回的原生档位；OpenAI 目录未提供的能力只按官方协议补充，未知能力不猜测。供应商默认省略 `reasoning_effort`，已选模型中的设置作为以后选择该模型时的默认值；会话可以在输入框旁单独选择强度。

修改默认模型与默认强度只影响之后的新会话或新选择。在途请求和已启动的上下文整理任务保留启动时的设置。

## 网络搜索

在「设置 → 模型配置 → 网络搜索」启用搜索并选择服务。搜索模型独立于聊天模型列表。

1. 选择 DeepSeek 或 OpenAI 时，复用当前数据目录的 `connections.json` 中的 `deepseek.api_key` 或 `openai.api_key`。选择「ChatGPT 订阅」时，复用在「供应商与模型」完成的 [ChatGPT 授权](#使用-chatgpt-订阅额度)，使用该账号的订阅额度。
2. OpenAI 和 ChatGPT 订阅从各自目录选择支持搜索的模型。DeepSeek 无需选择搜索模型。
3. 输入问题，点击「测试搜索」检查当前草稿，再点击「保存搜索配置」供 Bot 使用。测试会实际请求服务并消耗相应的 API 用量或订阅额度，草稿在点击保存后才生效。

| 选择 | 测试与使用时会得到什么 |
|---|---|
| DeepSeek | 来源链接与摘要；Bot 还可读取网页原文，不额外编造模型回答 |
| OpenAI、ChatGPT 订阅 | 搜索模型的回答与来源，并标明是否实际检索。“模型直接回答，未联网”不能作为已核实的最新信息 |

同一数据目录的 Bot 共用搜索偏好，独立保存在连接文件旁的 `search.json`，不改 `config.json` 中的聊天候选、默认值或会话选择。文件不存在时默认启用 DeepSeek，仍需对应密钥。停用保留服务与模型选择，不再向 Bot 提供该内置搜索；已安装的其他搜索 MCP 和浏览器不受影响。

保存后，Bot 在下一次判断取得能力变化，按需加载工具；连接密钥更新在后续调用生效，无需重启。配置齐全不保证认证、账号权限或网页访问成功，测试失败会展示原因。能力与证据边界见[网络搜索](架构/能力/网络搜索.md)。

## 图片生成

在「设置 → 模型配置 → 图片生成」启用功能，从当前 OpenAI 连接返回的图片模型目录中选择型号，然后点击「保存图片配置」。复用 `connections.json` 中的 `openai.api_key`，无需另存密钥；不使用 Codex 登录额度，也不要求 Bot 的聊天模型来自 OpenAI。

保存只改变配置，不发起付费生成。在 Bot 对话中描述所需图片，Bot 按需加载图片工具。第一版支持文字生成单张图片，可指定尺寸、质量、背景和 PNG、JPEG 或 WebP 格式；具体参数与模型权限以供应商实际支持为准。生成按 OpenAI 用量计费。

原图保存在 Bot 当前工作目录的 `generated-images/`，工具同时返回相对路径、原图尺寸与独立预览。工具预览会缩小；Bot 用 `send_file` 发送原图后，对话只展示图片，点开放大可下载原图。正文说明可选，不固定附加文件名、大小或发送确认。请求中断不能证明没有生成，不会自动重发付费请求；先核对供应商用量，再决定是否重新生成。

同一数据目录的 Bot 共用图片偏好，保存在连接文件旁的 `image-generation.json`，与聊天和搜索设置分开。首次默认停用，停用后保留模型选择。配置更新后下一次判断取得能力变化，密钥在每次调用时读取，无需重启。边界与取舍见[媒体生成](架构/能力/媒体生成.md)。
